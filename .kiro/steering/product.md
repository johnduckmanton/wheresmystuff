# Product Overview

## Home Inventory System

A comprehensive serverless web application for tracking and managing personal belongings across multiple locations with advanced QR code functionality.

### Core Purpose
- Track containers and items across multiple physical locations
- Generate and scan QR codes for instant container access
- Manage inventory with role-based user collaboration
- Support moving projects and storage organization

### Key Features
- **Container Management**: Track containers with detailed information and status
- **QR Code System**: Generate unique QR codes for containers with mobile scanning
- **Multi-User Support**: Role-based access (Owner, Admin, Member, Read-only) with invitations
- **Photo Management**: Upload and view photos with S3 storage
- **Location Organization**: Organize by physical addresses, rooms, and floors
- **Moving Projects**: Specialized workflows for relocation scenarios

### Target Users
- Individuals and families managing household inventory
- People planning moves or relocations
- Organizations tracking equipment across locations
- Anyone needing systematic item organization with mobile access

### Business Model
- Personal/family use focused
- Serverless architecture for cost efficiency
- Multi-region deployment (Backend: eu-west-1, CDN: us-east-1)
