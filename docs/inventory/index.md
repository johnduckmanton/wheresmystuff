# Inventory Management

The inventory system is the heart of Where's My Stuff!. It lets you catalog your belongings and organize them by location, room, category, and owner.

## Core Concepts

### Inventories

An **inventory** is the top-level grouping for all your data. Each inventory has its own set of things, locations, rooms, categories, and people. You can create multiple inventories (e.g., one per household) and switch between them using the inventory selector in the sidebar.

### Things

**Things** are the individual items you're tracking — furniture, electronics, clothing, tools, anything you own. Each thing can have:

- A name and description
- Make, model, and serial number
- Photos (with optional AI recognition)
- Tags for search and filtering
- A location and room assignment
- A category and owner
- Purchase and warranty details
- Notes

For full details, see [Managing Things](things.md).

### Locations

**Locations** represent physical places: your home, a storage unit, an office, a relative's house. Each location can have an address and a description.

For full details, see [Locations & Rooms](locations.md).

### Rooms

**Rooms** are subdivisions within a location. A room belongs to exactly one location and can represent a literal room (kitchen, bedroom) or any area that helps you organize (garage shelf, closet, attic).

### Categories

**Categories** let you classify things by type. Examples: Electronics, Furniture, Clothing, Books, Kitchen. Each category can have a name, description, and color for visual identification.

### People

**People** represent the owners of things in your inventory. This is useful for shared households where you want to track who owns what. Each person can have:

- A name
- Email and phone number
- Relationship (e.g., "Spouse", "Roommate", "Child")
- Notes
- A photo / avatar

## Sidebar Navigation

The inventory section in the sidebar gives you quick access to:

- **Things** — View and manage all items
- **Locations** — Manage locations and rooms
- **Categories** — Create and edit categories
- **People** — Manage people / owners

Use the inventory selector at the top of the sidebar to switch between inventories if you have more than one.

## Search and Filtering

Most list views in the app support searching and filtering:

- **Text search** — Search by name, description, or other fields
- **Tag filtering** — Filter things by tags
- **Category filtering** — Show only items in a specific category
- **Location filtering** — Show items at a specific location

You can combine filters to narrow down results. For example, search for "laptop" within the "Electronics" category at your "Home" location.
